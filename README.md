# MyMoney

Приложение для управления личными и семейными финансами. Android MVP, iOS — на горизонте.

## Стек

**Backend:** Kotlin + Ktor + PostgreSQL + Exposed + Koin + JWT, Clean Architecture, миграции Flyway.
**Mobile:** Flutter + Riverpod + Isar + Dio, Clean Architecture, Offline First.
**Валюта на MVP:** только RUB, суммы хранятся как целые копейки (`BIGINT` / `Int64`).

## Философия (кратко)

Приоритеты, в порядке важности: **Простота → Скорость → Надёжность → Безопасность → Понятность.**
Offline First — архитектурный контракт, не опция. Локальная БД — источник истины на устройстве. Цель — добавление операции ≤ 3 шагов, < 10 сек (см. UC-03/UC-04 Bible).

## Как запустить и тестировать

**Полное практическое руководство — [`HOWTO_RUN.md`](HOWTO_RUN.md).**
Там разложено: что установить на ПК, как поднять бэкенд, как собрать APK,
как подключить Android-смартфон и как вручную проверить приёмочные
сценарии Этапа 1 (в т.ч. ключевой DoD «добавить операцию за ≤ 3 шага»).

Короткая версия:

```powershell
# Backend (по желанию — мобильное приложение работает offline-first)
Copy-Item .env.example .env
docker compose up -d postgres
cd backend
.\gradlew.bat run

# Mobile
cd mobile
flutter pub get
dart run build_runner build --delete-conflicting-outputs
flutter run                # на подключенный телефон / эмулятор
```
